# adHOME Creative — agency website

A presentation-led, responsive website designed around the agency's real services, portfolio and project enquiries. This is a new design direction; no shopping, inventory or payment functionality is included.

Public website: https://gout648.github.io/adhome-creative/

Repository: https://github.com/GOUT648/adhome-creative

## Run locally

From this folder run `python -m http.server 5175` and open http://127.0.0.1:5175.

## Content and interactions

- Original lime/teal design direction informed by the agency's Instagram and official website.
- Four real project stories, filterable by branding, campaigns and digital.
- Accessible project dialogs with links to the original source material.
- Service accordions, service-to-enquiry selection and responsive navigation.
- A project brief form with browser validation, preview, copy and a mailto draft to the verified agency email. It does not transmit submissions automatically.
- Photography, illustration and project assets from the agency's public material, served locally.
- No invented prices, results, testimonials, response-time promises or personnel biographies.

## Files

`index.html` contains page structure and English copy. `style.css` contains the responsive visual system. `script.js` contains project data, filtering, dialogs and the project brief. `assets/` contains local images and fonts. GitHub Pages publishes the main branch from the repository root.

For another hosting provider, upload the contents of this folder. All navigation and asset paths are relative. Update absolute sharing/schema URLs if the destination changes.
